# Changelog

## 0.1.0

- Require Flutter 3.44 or newer and Dart 3.12 or newer for Flutter's Built-in
  Kotlin plugin-author integration.
- Support both CocoaPods and Flutter Swift Package Manager from one Swift
  source tree.
- Keep Git/path distribution only. Publication is intentionally deferred while
  the `workspace` dependency name is owned by an unrelated hosted package.
